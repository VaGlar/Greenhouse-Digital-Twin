# Greenhouse Digital Twin (MVP v1: Climate + Yield)

Παραμετροποιήσιμο digital twin για θερμοκήπιο υδροπονίας τομάτας με μηχανή
συμπαραγωγής (CHP). Δίνεις τις πραγματικές παραμέτρους του θερμοκηπίου σε
ένα YAML config και το twin τρέχει μια πλήρη καλλιεργητική περίοδο,
προσομοιώνοντας το εσωτερικό μικροκλίμα ώρα-προς-ώρα και βγάζοντας πρόβλεψη
παραγωγής τομάτας.

Αυτό είναι το **v1 MVP**: κλίμα + παραγωγή, end-to-end, τίποτα άλλο. Πρόβλεψη
ασθενειών, real sensor calibration και control/optimization layer είναι
σκόπιμα εκτός v1 — θα προστεθούν ως modules πάνω στο ίδιο θεμέλιο χωρίς να
χρειαστεί ξαναγράψιμο του πυρήνα.

## Γρήγορο ξεκίνημα

```bash
pip install -r requirements.txt
python run_simulation.py --config config/greenhouse_example.yaml
```

Παράγει `outputs/results.csv` (ωριαία time series) και `outputs/results.png`
(γραφήματα θερμοκρασίας, CO2, σωρευτικής παραγωγής).

Τρέξιμο των tests:

```bash
pytest tests/
```

## Πώς να το παραμετροποιήσεις για το πραγματικό θερμοκήπιο

Όλες οι παράμετροι ζουν σε ένα YAML αρχείο (βλ. `config/greenhouse_example.yaml`
για ένα πλήρες παράδειγμα με 5.000 m², CHP 1MW, τομάτα). Αντίγραψε το και
άλλαξε τιμές — δεν χρειάζεται να αγγίξεις κώδικα:

- **`geometry`** — εμβαδόν, ύψος, μονωτικές ιδιότητες κάλυψης (U-value),
  διαπερατότητα φωτός.
- **`chp`** — ηλεκτρική ισχύς CHP (σταθερή), λόγος θερμότητας/ηλεκτρισμού,
  CO2 ανά kWh ηλεκτρικού.
- **`climate_control`** — setpoints θερμοκρασίας ημέρας/νύχτας, όρια
  αερισμού, setpoint CO2.
- **`crop`** — ποικιλία, ημερομηνία φύτευσης, πυκνότητα φύτευσης, παράμετροι
  ανάπτυξης.
- **`weather`** — `synthetic` (default, sinusoidal γεννήτρια) ή `csv` με
  πραγματικά ιστορικά δεδομένα καιρού της περιοχής.
- **`simulation`** — ημερομηνία έναρξης, διάρκεια, χρονικό βήμα.

## Βασική παραδοχή μοντελοποίησης: το CHP δεν "ακούει" το θερμοκήπιο

Η ηλεκτρική έξοδος του CHP είναι **σταθερή** (καθορίζεται από ζήτηση/εξαγωγή
ηλεκτρισμού στο δίκτυο, όχι από τις ανάγκες του θερμοκηπίου). Άρα και η
θερμική έξοδος και η έξοδος CO2 από τα καυσαέρια είναι επίσης σταθερές. Το
θερμοκήπιο απορροφά όση θερμότητα/CO2 χρειάζεται για να φτάσει τα setpoints
του· η περίσσεια αποβάλλεται (dump θερμότητας, bypass CO2 στην ατμόσφαιρα) —
το CHP δεν διαμορφώνεται ποτέ βάσει κλιματικών αναγκών.

## Αρχιτεκτονική

```
config/greenhouse_example.yaml   # παράδειγμα, παραμετροποιήσιμο config
twin/
  params.py           # validated schema όλων των παραμέτρων (YAML -> dataclasses)
  weather.py           # εξωτερικός καιρός: CSV ιστορικού ή synthetic generator
  climate_model.py     # ωριαίο ενεργειακό + CO2 ισοζύγιο θερμοκηπίου (GreenLight-lite)
  crop_model.py         # φωτοσύνθεση/βιομάζα/παραγωγή τομάτας (TOMGRO-lite)
  simulate.py            # ενορχηστρώνει το climate+crop loop ώρα-προς-ώρα
run_simulation.py         # CLI entrypoint
tests/                     # unit sanity tests (climate model, crop model)
```

Το `climate_model.py` και το `crop_model.py` είναι εμπνευσμένα από τη δομή
των ακαδημαϊκών μοντέλων **GreenLight** (Wageningen University, ενεργειακό
ισοζύγιο θερμοκηπίου) και **TOMGRO** (ανάπτυξη/παραγωγή τομάτας) — δεν είναι
πιστά ports, αλλά σκόπιμα απλοποιημένες εκδοχές τους, ώστε να είναι εύκολο
να διαβαστούν, να ελεγχθούν και αργότερα να βαθμονομηθούν με πραγματικά
δεδομένα αισθητήρων.

## Γνωστοί περιορισμοί του v1 (σκόπιμα εκτός scope)

- Καμία πρόβλεψη ασθενειών (θα προστεθεί ως module πάνω στο climate output —
  π.χ. risk models για Botrytis/ωίδιο βάσει υγρασίας/θερμοκρασίας).
- Κανένα real sensor data ingestion / calibration loop.
- Κανένα optimization ή control layer (rule-based ή RL controller).
- Single-zone κλιματικό μοντέλο (όχι multi-zone).
- Το υδροπονικό σύστημα είναι μόνο flag (`hydroponic.system_type`) — δεν
  μοντελοποιείται σε βάθος (θρεπτικά, EC/pH) ακόμα.
- Χωρίς μοντέλο υγρασίας (RH) στο εσωτερικό — μόνο θερμοκρασία και CO2.
- Οι τιμές παραμέτρων φωτοσύνθεσης/ανάπτυξης στο `crop_model.py` είναι
  βιβλιογραφικά τυπικές για θερμοκηπιακή τομάτα, όχι βαθμονομημένες σε
  συγκεκριμένη ποικιλία/τοποθεσία — χρειάζονται recalibration με πραγματικά
  δεδομένα παραγωγής όταν γίνουν διαθέσιμα.
